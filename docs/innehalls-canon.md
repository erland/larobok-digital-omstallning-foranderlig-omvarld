# Innehålls-canon

- Språk: svenska; typ: analytisk faktabok; nivå: fördjupad men pedagogiskt tillgänglig.
- Organisation: beskriv alltid en *generell samhällsviktig statlig myndighet* med gränsöverskridande flöden, kontroll, tillsyn, uppbörd och brottsbekämpning.
- Nämn inte en enskild konkret myndighet som bokens implicita huvudperson.
- Exempel: fiktiva och tydligt markerade; inga verkliga interna system, organisationer eller arbetssätt ska påstås.
- Fakta, analys och scenario skiljs åt.
- Källbaslinje: eSam februari 2026; nya förhållanden versionsdateras.
- Återkommande analyskedja: omvärld → verksamhetsförmåga → rättsliga villkor → data → teknik → säkerhet → användare → strategiskt vägval.
- Inga bindande rättsliga tolkningar eller operativa instruktioner för brottsbekämpning.
