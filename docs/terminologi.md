# Terminologi

| Term | Arbetsdefinition |
|---|---|
| Radarbild | Systematiserad överblick av relevanta omvärldsförändringar och initiativ. |
| Verksamhetsförmåga | Organisationens samlade förutsättningar att åstadkomma ett resultat. |
| Interoperabilitet | Förmåga hos organisationer och system att samverka och använda utbytt information. |
| Datastyrning | Ansvar, principer och processer för hantering av data som resurs. |
| Riskbaserad kontroll | Prioritering av kontrollinsatser med stöd av bedömda risker och rättsliga förutsättningar. |
| Digital suveränitet | Möjlighet att utöva kontroll över relevanta digitala beroenden och vägval. |
| Mänsklig kontroll | Meningsfull möjlighet till mänsklig bedömning och ingripande i ett AI-stött förfarande. |
